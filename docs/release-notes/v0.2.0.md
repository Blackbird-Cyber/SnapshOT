# SnapshOT 0.2.0 (pre-release)

This is a pre-release. It replaces the v0.1.0 preview and is the first image
with a working installer, but the installer has not yet been run end to end on
VMware Fusion for this build (see Caveats). It will be promoted to a full
release after that run.

Debian 13 (trixie), pinned to snapshot.debian.org `20260901T022952Z`
(`SOURCE_DATE_EPOCH` 1788229792). Each image records its version, architecture,
pin and build commit in `/etc/snapshot-release`, and every package and vendored
tool in `/usr/share/snapshot/reference/BUILD-MANIFEST.txt`.

## Images

- `snapshot-amd64.hybrid.iso`: BIOS and UEFI, for x86-64 laptops and VMs.
- `snapshot-arm64.hybrid.iso`: UEFI only, for arm64 VMs (UTM, Parallels,
  VMware Fusion on Apple Silicon) and UEFI arm64 hardware. It does not boot an
  Apple Silicon Mac directly.
- `SHA256SUMS`: the SHA-256 of both images. Verify before writing the image;
  `docs/getting-started.md` shows how on Linux, macOS and Windows.

Live session: user `snapshot`, password `live`. Install with the Install
SnapshOT icon on the desktop.

## New since v0.1.0

- **The installer works.** The offline Calamares install writes an unencrypted
  1 GiB `/boot` and a LUKS2 root, so GRUB boots the installed system and the
  passphrase is asked once, at boot. Swap, when chosen, is a file inside the
  encrypted root.
  The live-only packages are removed from the installed system. The installed
  user is in group `sudo` (the password is remembered for 60 minutes) and in
  group `wireshark`, so Wireshark, tshark and termshark capture without sudo.
- **Dark desktop with eight menu folders.** SnapshOT-Dark theme, Papirus-Dark
  icons, one top panel and the Whisker menu with folders 01 Recon & Discovery
  to 08 Reference; 06 is Host Forensics.
- **The SnapshOT Wiki.** An offline site on the image
  (`/usr/share/snapshot/wiki`, opened from 08 Reference and the menu
  favorites) with a page per tool, the SANS PICERL lifecycle, MITRE ATT&CK for
  ICS, protocol primers and evidence handling. Search and graphs work offline.
- **The field kit.** A USB stick of read-only triage collectors for Windows (XP
  to 11, cmd and PowerShell) and Linux hosts. *Prepare Field Kit USB* writes the
  stick; *Import Field Kit results* brings the results into a case folder with
  hash checks, a read-only copy and a chain-of-custody log.
- **Firefox ESR, locked down.** An enterprise policy turns off telemetry,
  studies and updates, and the Remote Settings hosts resolve to loopback, so the
  browser sends nothing on its own. Its home page is the wiki.
- **The Sleuth Kit and TestDisk/PhotoRec** for disk and image examination on
  the command line, on both architectures.
- **The vendor layer.** Tools Debian does not carry, each under
  `/opt/snapshot/<tool>/` with its own pinned runtime (CPython 3.11) and
  reached through `/opt/snapshot/bin`: the ICS Python libraries (pymodbus with
  pyserial, pycomm3, BACpypes3, BAC0, asyncua, python-snap7) with the OPC UA
  command-line tools, the opcua-client GUI (amd64 only), plcscan and the
  Redpoint NSE scripts for nmap.
- **Receive-only radio.** RTL-SDR (dongle check and rtl_power), gqrx, and
  airodump-ng for a passive 802.11 survey. The image never transmits on radio.
  The aircrack-ng package is there only for airodump-ng; its other programs,
  including the key cracker, come with it but have no menu entry.
- **Quiet network defaults, extended.** Besides the masked avahi-daemon and
  time sync and the NetworkManager and resolver settings v0.1.0 already had,
  Firefox ESR stays silent, and 01 Recon & Discovery's mDNS entry listens
  passively with tshark.
- **The license.** Code under the Apache License 2.0, documentation and the
  wiki under CC BY 4.0, brand assets reserved (`TRADEMARKS.md`). The software
  comes with no warranty.

## Removed since v0.1.0

- The HackRF tools, GNU Radio and the SoapySDR tools: the radio slice is
  receive-only. gqrx still pulls in the gr-osmosdr library it needs.

## Caveats

- **Installer QA is not finished.** The installer configuration is validated in
  containers (`scripts/check-installer.sh`), and this build's live session was
  smoke-tested in QEMU (see Verified above). An end-to-end install on VMware
  Fusion has not been run on this build yet. Do not rely on a v0.2.0 install
  for an engagement until it has.
- **No hibernation.** Swap, when chosen, is a file inside the encrypted root,
  and the installer writes no resume parameter.
- **Firefox ESR gets no Remote Settings updates:** no certificate revocation
  (CRLite) or intermediate-certificate updates, no add-on blocklist and no
  security-list updates. Re-image rather than update in place.
- **Field kit manual QA is pending.** `scripts/check-fieldkit.sh` covers the
  collectors and tools in containers. Real USB sticks and Windows XP, 7 and 10
  VMs are still to be tested by hand. A bare Windows XP host reads the default
  exFAT stick only with KB955704; prepare the stick with
  `snapshot-fieldkit-prep --fat32` for one.
- **The offline update stick does not work yet.** `scripts/make-update-usb.sh`
  fails at its publish step with trixie's aptly. Re-image to change what is
  installed.

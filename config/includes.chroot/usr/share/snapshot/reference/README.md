# SnapshOT offline reference data
Populated at build time (BUILD-MANIFEST.txt) and by the source layer (e.g.
exploitdb). BUILD-MANIFEST.txt lists every vendored runtime and tool installed
under `/opt/snapshot` (from `/usr/share/snapshot/vendor/*.manifest`) alongside the
dpkg package list. Add offline copies of ATT&CK for ICS, CISA ICS advisories, and
vendor default-credential references here as fixed, versioned data.

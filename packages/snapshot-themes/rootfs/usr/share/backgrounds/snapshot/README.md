# SnapshOT wallpaper

`snapshot-default.png` is the SnapshOT splash (lockup, red rule, "made by
Blackbird" credit) at 1920x1080. Xfce is set to zoom it (image-style 5), so it
fills other aspect ratios; LightDM uses the same file. The source composition and
the full asset set live in `branding/` at the repo root. Committed assets must be
fixed files so the build stays reproducible.
